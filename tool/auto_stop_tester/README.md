# 自动关播断流测试工具

这是一个仅绑定 `127.0.0.1:19090` 的本地 FLV 测试源，用来完整验证：

`OBS 拉流 → 测试工具断流 → 客户端判定源直播结束 → 直播伴侣自动关播`

## 使用

1. 打开 `自动关播断流测试工具.exe`。
2. 复制工具里的地址，粘贴到快马小助手的直播间输入框。
3. 选择快手或抖音直播伴侣，开启“源直播结束后自动关播”。
4. 点击“一键开播”，等 OBS 出现测试画面。
5. 点击工具的“立即断流”。
6. 等待约 18–25 秒，观察直播伴侣是否收到关播快捷键并自动确认。

点击“开始 / 恢复供流”可继续下一次测试。新一轮需在快马小助手里再次点击“一键开播”，以重置结束防重入状态。

## 构建

```powershell
powershell -ExecutionPolicy Bypass -File tool\auto_stop_tester\build.ps1
```

构建产物：`dist\auto-stop-stream-tester.exe`
