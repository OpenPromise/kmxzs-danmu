# 补充：无域名 HTTP 运营注意

正式部署步骤见 [README.md](./README.md)。

## 安全建议

1. `.env` 不要提交仓库、不要发给用户  
2. `KMXZS_API_SECRET` 泄露 → 换新密钥并强制用户升级客户端  
3. 卡密泄露 → 管理后台停用该卡  
4. 管理 Token 只放自己电脑；后台尽量 SSH 隧道访问  
5. 桌面端无法绝对防破解；卡密以服务端校验为准，短周期发卡更稳  

## 客户端防绕过（已实现）

HMAC 签名、nonce/时间窗、Release 禁用 localMock、周期在线验权、过期阻断一键开始、会话复核设备/过期。
